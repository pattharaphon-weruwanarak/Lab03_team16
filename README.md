# Lab03_team16

## `cleaner.py`

### สมาชิก 3

ฟังก์ชัน `clean_text(text)` ตัดช่องว่างหน้า–หลัง และยุบช่องว่างซ้ำให้เหลือช่องเดียว

- `clean_text("  hello   world ")` → `"hello world"`
- `clean_text("a  b ")` → `"a b"`

## `reverser.py`

### สมาชิก 2

ฟังก์ชัน `reverse_words(text)` กลับลำดับคำในข้อความ โดยคั่นคำในผลลัพธ์ด้วยช่องว่างหนึ่งตัว

- `reverse_words("hello first year")` → `"year first hello"`
- `reverse_words("a  b")` → `"b a"`
